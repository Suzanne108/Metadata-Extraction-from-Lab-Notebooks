[2026-01-13 11:25:43] Step: ISA overview
   Content: ISA is a simple, structured way to describe how an experiment was done, so others can understand, reuse, and reproduce it. It organizes metadata across three levels and keeps the language consistent across projects.

Key idea
- ISA stands for Investigation, Study, and Assay. Think of it as a stack: a project (Investigation) contains experimental units (Studies), and each unit has specific measurements (Assays).
- The focus is on what was done, with what, how, and where the results live, using standardized terms when possible.

Main components and how they relate
- Investigation
  - The project-wide container: title, description, who worked on it, any publications, and references to ontology terms used across the project.
  - Holds a list of Studies and any general project-level information.
- Study
  - A coherent experimental unit within the project. Each Study has its own title, description, and design descriptors (how the study was planned).
  - Contains: protocols used, materials (sources, samples, other materials), any processes that link steps, the Assays run in the study, and factors that describe experimental variables (e.g., genotype, treatment).
  - May include people, publications, and ontology-annotated descriptors for consistency.
- Assay
  - A specific measurement or observation within a Study. Think of it as a single data-producing activity.
  - Includes: what was measured (measurementType), how it was measured (technologyType), any data files produced, and related materials (samples or other materials). It can also reference the protocols used for the measurement and the processes involved.

Common objects you’ll see
- Protocols
  - Standardized methods or procedures used in a Study or Assay. They often include a protocolType, parameters, and components.
- Processes
  - The concrete steps executed in time order that implement protocols or parts of workflows.
- Materials
  - Different kinds of inputs: Sources (e.g., plant seeds), Samples (e.g., labeled tissue), and Other Materials (e.g., reagents). Each can have characterizations.
- Factors
  - Experimental variables that define conditions (e.g., genotype, treatment level). They describe how a Study was varied.
- Data files
  - The actual results or intermediate files produced by Assays (e.g., raw data, derived data, images).
- Ontology annotations
  - Standardized terms to describe concepts like measurement type, units, or traits. They help map terms to recognized vocabularies and enable cross-study searches.
- Ontology sources and accession references
  - Links to the vocabulary sources used (e.g., species, traits, technologies) so others can trace the exact terms and IDs.

What to look for in typical life-science articles (quick checklist)
- Investigation level
  - Project title and a concise description of the overall goal.
  - Any author affiliations and a list of related publications or datasets.
  - Clear statement of the ontology sources used (what terms come from which vocabularies).
- Studies within the Investigation
  - Each Study has a descriptive title and description.
  - Study design descriptors (how the study was planned or randomized, etc.) annotated with ontology terms when possible.
  - Protocols used in the Study (names, types, and any key parameters).
  - Materials listed for the Study: sources, samples, and any other materials with basic identifiers.
  - Factors describing experimental variables (e.g., genotype, treatment, time).
  - Process sequences showing how steps are connected.
  - Any assays reported in the Study (what was measured and how).
- Assays and data
  - For each Assay: what was measured (measurementType) and how (technologyType).
  - Data files produced (names or links, and their type e.g., raw, derived, image).
  - Linkages to the Study’s materials (which samples or other materials were measured).
  - Any protocol or process references tied to the assay.
- Standards and reuse
  - Any ontology annotations or standardized terms used, with sources and IDs if provided.
  - Clear references to where data can be found (repositories, file names, accession numbers).
- Practical signs
  - Look for explicit lists: Investigation → Studies → Protocols, Materials, Assays, Data files.
  - Reusable language: standardized terms, clear variable names, and documented experimental steps.
  - Consistent naming for samples, materials, and data to avoid ambiguity.

A simple mental model to carry forward
- Imagine a project notebook (Investigation). Inside it are chapters (Studies). In each chapter, you have experiments that produce results (Assays), using defined methods (Protocols) and inputs (Materials). The metadata ties everything together with variables (Factors) and standard terms (Ontology Annotations) so you can understand and reuse the work later.
