

Current problems/observations:

- No feedback mechanism for feedback on content of the isa metadata created, only on the correct JSON format
- Trouble with required ontology annotations. Support for this has not been implemented yet. Now some random value is used. 
  Implementation would require an agent that can look online for the correct annotation and refer to it.
- Depending on the size of the reference document, a lot of tasks can be created. The whole process takes a long time to complete.
- Still a lot of schema validation errors which make the whole process longer, because more correction loops are necessary.
- The workflow gives different behaviour depending on the run. Especially in the document overview and planning nodes. 
    - Sometimes document overview identifies 2 Study objects, sometimes 4. Sometimes task planner creates 27 tasks, sometimes 44.
